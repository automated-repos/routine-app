# روتيني 🌱 تطبيق تتبع العادات

تطبيق ويب (Next.js، ملفات static) بقاعدة بيانات Supabase. ممكن يترفع على Netlify أو GitHub Pages، والمستخدم يقدر يضيفه للشاشة الرئيسية على الموبايل (Android وiPhone) ويفتحه كأنه تطبيق.

## المميزات
- **عادات يومية وأسبوعية وشهرية**، ولكل عادة عدد مرات (مثلاً رياضة 3 مرات في الأسبوع).
- **ترتيب المهام على مواعيد الصلاة** (اختياري من الإعدادات): المواعيد بتتحسب على الجهاز بمكتبة `adhan`، وتقدري تختاري طريقة الحساب والمذهب.
- **نجوم**: نجمة لكل تنفيذ، وبونص لما الهدف يكمل (يومي +1، أسبوعي +3، شهري +10). الحساب كله بيتم في قاعدة البيانات، والحد الأقصى 50 نجمة تنفيذ في اليوم.
- **قوائم شرف منفصلة**: يومي، أسبوعي، شهري، ونجوم، ولكل قائمة فترة (الأسبوع ده، الشهر ده، من البداية). المستخدم يقدر يخفي اسمه.
- **تحديات من الأدمن** ليها بونص نجوم:
  - *تلقائي*: بيتحسب من سجل العادات (مثلاً 20 تنفيذ في أسبوع).
  - *يدوي*: المستخدم يطلب البونص والأدمن يوافق أو يرفض.
- **تنبيهات جوه التطبيق**: المهمة الجاية، مهام فات ميعادها، "بقالك X أيام مسجلتيش"، الأسبوع أو الشهر قرب يخلص، تحديات جديدة. وطول ما التطبيق مفتوح بيظهر إشعار من المتصفح لما ييجي ميعاد مهمة.
- **صفحة الحساب**: أيام متتالية (streak)، أطول سلسلة، خريطة نشاط، شارات، وسجل البونصات.
- **لوحة أدمن**: إضافة ومسح التحديات، الموافقة على الطلبات، وإضافة أو خصم نجوم.

## التشغيل

### 1) Supabase
1. اعملي مشروع جديد على [supabase.com](https://supabase.com).
2. من **SQL Editor** شغّلي محتوى [supabase/schema.sql](supabase/schema.sql) كله. ممكن تعيدي تشغيله بأمان بعد أي تعديل.
3. من **Authentication > URL Configuration** حطي رابط الموقع في **Site URL** (وأثناء التطوير `http://localhost:3000`).
4. **مهم:** التطبيق بيستخدم اسم مستخدم بدل الإيميل، فلازم تقفلي التأكيد: **Authentication > Sign In / Providers > Email** واقفلي **Confirm email**.

### 2) التشغيل على الجهاز
```bash
cp .env.example .env.local   # وحطي فيه URL و anon key من Project Settings > API
npm install
npm run dev
```

### 3) تخلي نفسك أدمن
بعد ما تسجلي حساب من التطبيق، شغّلي في SQL Editor:
```sql
update public.profiles set is_admin = true where username = 'YOUR_USERNAME';
```

## تسجيل الدخول باسم مستخدم
- المستخدم بيكتب اسم مستخدم وباسورد بس. التطبيق بيحوله في الخلفية لإيميل داخلي (`username@routine.local`) لأن Supabase محتاج إيميل، ومحدش بيستلم عليه حاجة.
- **نسيان الباسورد:** مفيش إيميل يتبعت عليه، فالأدمن بيغير الباسورد من لوحة الأدمن (زرار 🔑 جنب المستخدم).
- لو عايزة تقفلي التسجيل المفتوح وتضيفي الناس بنفسك: **Authentication > Sign In / Providers** واقفلي **Allow new users to sign up**.

## الرفع

### Netlify (الأسهل)
1. ارفعي الكود على GitHub، وبعدين في Netlify اختاري **Add new site > Import from Git**.
2. الإعدادات بتتقري تلقائي من `netlify.toml`.
3. في **Site settings > Environment variables** ضيفي `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY`.

### GitHub Pages
1. في الريبو: **Settings > Pages > Source = GitHub Actions**.
2. **Settings > Secrets and variables > Actions** وضيفي `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY`.
3. أي push على `main` بيرفع تلقائي (الملف في [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml)).
4. الموقع هيبقى على `https://<user>.github.io/<repo>/`. حطي الرابط ده في Site URL في Supabase.

> الـ anon key مفيش مشكلة إنه يبقى في الكود اللي بيتبعت للمتصفح، لأن الحماية كلها من RLS في قاعدة البيانات. **متحطيش** الـ `service_role` key أبداً.

## هيكل المشروع
```
supabase/schema.sql      الجداول + RLS + الدوال (النجوم، قوائم الشرف، التحديات)
src/lib/                 Supabase client، التواريخ، مواعيد الصلاة، تحميل مهام النهارده
src/components/          AuthProvider، AppShell (التنقل + حماية الصفحات)، التنبيهات، كارت العادة
src/app/                 الصفحات: / ، habits ، leaderboard ، challenges ، profile ، settings ، admin ، login
```

## ملاحظات
- الأسبوع بيبدأ يوم **السبت**.
- اليوم بيتحسب حسب المنطقة الزمنية للمستخدم (من الإعدادات). قوائم الشرف بتتحسب بتوقيت القاهرة.
- "إيقاف" العادة بيخفيها ويحافظ على سجلها ونجومها، أما "مسح" فبيمسح كل حاجة تخصها.
